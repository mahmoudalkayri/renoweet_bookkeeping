Renoweet setup: keep only this interface on GitHub Pages. Keep the bookkeeping XLSX in your local OneDrive-synced folder. Click Connect OneDrive workbook once and choose the XLSX from that folder. Edits are then written directly to that local file and OneDrive syncs it automatically. Your bookkeeping file does not need to be uploaded to GitHub. Deleted invoices/expenses are moved to a separate Deleted sheet and excluded from all totals until you remove them manually.
